# Hero image

## Single composite (recommended)

| Path | Description |
|------|-------------|
| `website/public/assets/hero/phone.png` | One image showing all phones (Inkitt-style) |

URL in the app: **`/assets/hero/phone.png`**

### Your machine

Put the file here:

```
C:\lakmal_code\novel_v7\website\public\assets\hero\phone.png
```

Then restart or hard-refresh:

```cmd
cd C:\lakmal_code\novel_v7\website
npm run dev
```

Press **Ctrl+F5** in the browser.

Book covers still load from the backend `/uploads/...` (same database as the mobile app).
